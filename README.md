# Agentic Reltio Data Quality GA

Create a pixel-perfect web application based on the provided Figma frame.

Goal

Replicate the design exactly as shown in the reference frame with precise adherence to layout, spacing, typography, colors, and component structure.

Design Fidelity Requirements

Match all spacing, padding, and margins exactly as in the frame

Use the exact color styles (design tokens) from the file (no approximations)

Apply the same typography system including font family, size, weight, line height, and letter spacing

Maintain border radius, shadows, and elevation as defined

Follow the exact grid and alignment rules

Component Structure

Break the UI into reusable components (e.g., header, sidebar, cards, buttons, inputs, tables)

Ensure each component reflects the exact visual states from the design (default, hover, focus, disabled if visible)

Maintain consistent spacing and hierarchy between components

Layout Behavior

Recreate the layout structure exactly (top navigation, side panels, content areas, etc.)

Preserve visual hierarchy and grouping

Ensure scroll behavior matches the design (fixed headers, sticky sections if applicable)

Styling Approach

• Use design tokens for:

Colors

Typography

Spacing

Shadows

• Keep styles consistent and reusable across components

Interactions (if visible in design)

Implement hover, focus, and active states as shown

Add basic UI interactions (button clicks, dropdowns, tabs) if they are implied

Code Quality

Use clean, modular structure

Prefer reusable components over hardcoded layouts

Keep styling scalable and maintainable

Output Expectation

A high-fidelity web UI that visually matches the Figma frame exactly, with no deviation in spacing, color, or typography.

Do not simplify or reinterpret the design—focus on exact replication.
